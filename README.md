# Task Manager API

A beginner-friendly Task Manager API built with Python,FastAPI, and SQLite.

# Features

- Create new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Store tasks permanently using SQLite

# Technologies Used

- Python
- FastAPI
- SQLite
- Uvicorn

# How to Run

Install the required packages:

```bash
python -m pip install fastapi "uvicorn[standard]"
